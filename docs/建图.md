## z_lio+ma_nav 参数调整

1. backend.yaml common.scan_context.lidar_height 相对地面的高度

2. backend.yaml  trajectory.map_voxel_resolution 若后续直接把 map.pcd 给 ma_nav 的 static_map_builder（0.05 m 栅格）建图，同步

3. backend.yaml common.body  old哨兵倒置 roll: 180, offset: [0.038, 0, -0.433] (LiDAR 光心-->云台)   

body:
    rotation:
      roll_deg: 180.0
      pitch_deg: 0.0
      yaw_deg: 0.0
    offset:
      # IMU -> 云台(body)，在 body 系下表达
      x: 0.027
      y: 0.02329
      z: -0.47712

4. lio.yaml sensor.body_from_lidar Mid-360 无需改动


5. planner.yaml  ros2.frame_id 与 z-localization 的 common.map_frame 一致（ma_nav 不做 TF 变换）

6. planner.yaml  ros2.map_topic_name "/localization/lio_world_cloud" 接入后端变换到 map 系的实时点云

7. planner.yaml ros2.odom_topic_name  "/localization/body_odometry"	 唯一与 ma_nav 同约定的话题（正立 body 位姿 + map 系杆臂补偿速度）

8. planner.yaml  ros2.map_odom_topic_name （置空

9. planner.yaml  map.mapping_model	false	在线建图改 true，导航验证改 false	控制 ma_nav 走 OnlineTerrainMapper 还是 DynamicStvlLayer



## 流程(ros2bag)

核心原则：不要在 z-localization 第一次 mode:=mapping 时同步跑 ma_nav 建图（回环优化会拉动历史位姿，但 ma_nav 增量 3D 体素不会跟着移，会产生双层墙重影）。按以下 4 步走，定位与导航地图天然四维同系（X, Y, Z, Yaw）：

所有终端先执行：
```sh
cd /home/xyt/MA_2027_Sentry
source install/setup.sh
```
步骤 1：用 Bag 跑 z-localization 无 UWB 建图并保存原始包
- 终端 1（启动建图，用 pcd/site.yaml 关闭 UWB）：
```sh
ros2 launch z_localization_bringup bringup.launch.py \
  frontend_config:="$PWD/src/location/z-localization/config/lio.yaml" \
  backend_config:="$PWD/src/location/z-localization/pcd/site.yaml" \
  mode:=mapping use_sim_time:=true imu_acceleration_scale:=9.81 rviz:=true
```
- 终端 2（播放 bag，必须带 --clock）：
```sh
ros2 bag play "$PWD/ros2bag/rosbag2_2026_11_25-00_04_21" --clock
```
- 播放完毕后，在终端 2 依次停止输入并保存地图（输出在 pcd/site_raw/）：
```sh
ros2 service call /stop std_srvs/srv/Trigger "{}"
```
# 等终端 1 日志不再有回环/关键帧更新（约 3~5 秒）后保存：
```sh
ros2 service call /backend_node/save_map std_srvs/srv/Trigger "{}"
```
看到 success=True 后 Ctrl+C 退出终端 1。
步骤 2：自动清理动态残影（+ 可选 CloudCompare 精修）
1. 自动 FreeDOM 清理（--lidar-origin 在 IMU 局部系，与整机倒置无关；--map-voxel 0.05 保留 5 cm 密度供 ma_nav 用）：
```sh
ros2 run backend clean_map_bundle \
  --in "$PWD/pcd/site_raw" \
  --out "$PWD/pcd/site_auto_clean" \
  --lidar-origin -0.011 -0.02329 0.04412 \
  --map-voxel 0.05
```
做到这里 pcd/site_auto_clean 已经自带重建好的 Scan Context 描述子，可以直接用于步骤 3 和步骤 4；如果动态残影不多，无需再跑后面精修。
2. （可选）CloudCompare 手工去噪后再入包：
- 若 apt 版 CloudCompare 打不开 .pcd，先转 .ply：pdal translate pcd/site_auto_clean/map.pcd pcd/site_clean.ply；清理完另存为 pcd/site_refined.pcd（不要平移/旋转坐标系，否则 filter_map_bundle 对不上）。
- 推荐（保留真实倒置扫描关键帧）：
```sh
ros2 run backend filter_map_bundle \
  --in "$PWD/pcd/site_auto_clean" \
  --out "$PWD/pcd/site_prior" \
  --reference-map "$PWD/pcd/site_refined.pcd" \
  --keep-distance 0.2 --map-voxel 0.05
```
- 仅当你主动在 CloudCompare 调平/改原点，需要按网格重建先验包时（务必显式传入倒置 FOV -52 到 7，x/y 范围按实际点云包围盒填）：
```sh
ros2 run backend build_pcd_map_bundle \
  --input "$PWD/pcd/site_refined.pcd" \
  --out-bundle "$PWD/pcd/site_prior" \
  --x-min -10 --x-max 20 --y-min -15 --y-max 15 \
  --sensor-z 0.0 --bundle-step 1.5 \
  --fov-down -52.0 --fov-up 7.0 \
  --map-voxel 0.05 --scan-voxel 0.4 \
  --descriptor-type scan_context --sc-lidar-height 0.60
```
步骤 3：接入 ma_nav 生成导航地图（二选一或对比）
- 路线 A（推荐，几秒离线出图，零重影，严格同 Z）：直接从清理后的 map.pcd 用 static_map_builder 生成 .pgm + .yaml + .terrain.bin 和诊断预览图（严禁加 --ground-to-zero）：
```sh
./build/ma_nav/src/test/static_map_builder \
  --input "$PWD/pcd/site_auto_clean/map.pcd" \
  --mode pcd \
  --output "$PWD/src/navigation/map/site_zlio" \
  --resolution 0.05 \
  --min-ground-z -1.2 --max-ground-z 0.5 \
  --pcd-min-pts 1 \
  --viz "$PWD/pcd/site_nav_viz"
```
检查生成的 pcd/site_nav_viz_{occ,ground,overhang}.png 确认墙壁清晰、地面连续。
- 路线 B（同步在线 STVL 建图：锚定在先验定位上，无回环跳变）：
1. 将 planner.yaml 改成 mapping_model: true（其余按上方第一部分改好）；
2. 终端 1 启 z-localization 先验定位（注意是 mode:=localization 而非 mapping）：
```sh
ros2 launch z_localization_bringup bringup.launch.py \
  frontend_config:="$PWD/src/location/z-localization/config/lio.yaml" \
  backend_config:="$PWD/src/location/z-localization/pcd/site.yaml" \
  mode:=localization prior_map:="$PWD/pcd/site_auto_clean" \
  use_sim_time:=true imu_acceleration_scale:=9.81 rviz:=false
````
3. 终端 2 启 ma_nav（use_sim_time:=true）：
```sh
ros2 launch ma_nav run.launch.py use_sim_time:=true rviz:=true
```
4. 终端 3 回放同一份 bag，观察 RViz 中 /ma_nav/map/static_3d 与 /ma_nav/grid_map_occ：
```sh
ros2 bag play "$PWD/ros2bag/rosbag2_2026_11_25-00_04_21" --clock
5. 回放完后在终端 3 保存 ma_nav 地图：
```sh
ros2 service call /save_global_map std_srvs/srv/Trigger "{}"
```
步骤 4：先验定位 + ma_nav 导航模式联调验证
1. 在 planner.yaml 中将 map.mapping_model: false，ros2.global_map_path 指向步骤 3 产出的 .pgm（例如 "src/navigation/map/site_zlio.pgm"，会自动加载同名 .yaml 和 .terrain.bin）；
2. 按步骤 3 路线 B 的终端 1、2、3 启动先验定位 + ma_nav + 回放 bag；
3. 在 RViz（Fixed Frame: map）核对：
- /localization/lio_world_cloud 墙面与 /ma_nav/grid_map_occ、/ma_nav/map/prior_ground 严丝合缝；
- /ma_nav/map/stvl_dynamic 在静态墙/地面/车身周围无误报，仅真实动态人/车出现且离开后 1~2 帧清除；
- ros2 topic echo /localization/body_odometry --once 验证姿态 roll/pitch ≈ 0°、position.z ≈ -0.43 m。
